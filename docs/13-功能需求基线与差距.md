## 1. 需求基线：九个页面

八个导航页 + 历史页。只列 P0 项与验收判据，完整条目见需求书。

| 页面 | P0 需求 | 关键验收判据 |
|---|---|---|
| 全局框架 | 导航与路由、标题栏与窗口控制、关闭保护、状态反馈、演示标识 | 逐项点击无白屏；有运行中部署时关闭须二次确认；禁止静默失败 |
| 新建任务 | 输入与发送、模型选择与成本展示、数据区域与私域策略、语音输入、结果回显 | 空内容不可发；出境模型警示；私域开关开启且本地模型不可用时**拒绝发送**，禁止静默改走云端 |
| 应用助手 | 应用管理、笔记管理、资料库、级联删除确认、本地持久化 | 重启三次数据不丢；删应用须提示笔记与资料一起删除 |
| 目标助手 | 目标管理、AI 生成五问、三阶段方案、进度计算 | 勾选后 200ms 内刷新；100% 时状态正确 |
| 学习助手 | 模块管理、提问生成、方案生成、提醒计划、完成度与评分 | 提醒时间非法须提示；评分边界值正确 |
| 本地资料 | 统计看板、分类树、搜索、详情预览 | **统计与磁盘实际文件数一致**；搜索 300ms 内出结果 |
| 技能部署 | 只读三步、双模式、硬件检测、技能库、软件匹配、方案生成与展示、网站授权、部署确认与进度、取消、结果汇总、安装包安全 | 只读三步前后运行目录无变化；同一时刻只允许一个部署；取消 5 秒内生效；解压拒绝 `..`、绝对路径、符号链接，总量上限 3 GiB |
| 系统设置 | 权限服务端校验、服务器配置 | 越权请求返回拒绝并记审计 |
| 版本更新 | 版本展示、检查更新 | 「已是最新」与「有新版本」文案互斥且准确 |
| 历史任务 | 任务列表、详情与恢复 | 按时间倒序；进行中任务可续，恢复后进度不丢 |

> **已取消**：「安装演练模式」（原 FR-SYS-03、FR-SKL-16）经决策取消，相关开关、配置项与用例一并作废。

## 2. 本地服务接口基线（18 项）

只监听 `127.0.0.1`。端口优先读环境变量（由桌面端注入空闲端口），未设置时回退 5085；**界面不得把端口写死**。

| # | 方法与路径 | 用途 | 现状 |
|---|---|---|---|
| 1 | `GET /api/health` | 健康检查 | ✅ |
| 2 | `GET /api/system/hardware` | 硬件信息，`refresh=1` 跳过缓存 | ✅ |
| 3 | `GET /api/skills/catalog` | 软件目录 | ✅ |
| 4 | `GET /api/sites/catalog` | 网站目录与分步动作 | ✅ |
| 5 | `POST /api/sites/resolve` | 按技能内容解析涉及网站 | ✅ |
| 6 | `POST /api/sites/open` | 打开指定站点页面 | ✅ |
| 7 | `POST /api/skills/match-software` | 逐行匹配软件，返回理由 | ✅ |
| 8 | `POST /api/auth/open` | 打开站点登录页 | ✅ |
| 9 | `POST /api/auth/confirm` | 确认已授权并写标记（含有效期） | ✅ |
| 10 | `POST /api/deploy/plan` | 生成方案（含授权步骤与警告） | ✅ |
| 11 | `POST /api/deploy/execute` | 启动部署，返回任务号 | ✅ |
| 12 | `GET /api/deploy/status` | 查询状态与各步进度 | ✅ |
| 13 | `POST /api/deploy/cancel` | 取消当前任务 | ✅ |
| 14 | `GET /api/deploy/history` | 历史部署记录 | ✅ |
| 15 | `GET /api/data/info` | 本地数据目录与占用 | ✅ |
| 16 | `GET /api/skills/custom` | 列出自建技能 | ✅ |
| 17 | `POST /api/skills/custom` | 新增或更新自建技能 | ✅ |
| 18 | `DELETE /api/skills/custom/{id}` | 删除自建技能 | ✅ |

### 2.1 接口通用约束

| 约束 | 要求 |
|---|---|
| 错误语义 | 一律带**中文可读原因**，不使用裸错误码 |
| 写接口 | 幂等或可安全重试 |
| 部署执行 | **异步返回任务号**，不阻塞请求 |
| 并发 | 同一时刻只允许一个部署任务，重复提交返回冲突 |

## 3. 数据实体与存储

| 实体 | 存储 | 生命周期 |
|---|---|---|
| 应用 / 笔记 / 资料条目 | 本机 | 用户删除即删；笔记随应用级联 |
| 目标 / 学习模块 | 本机 | 随上级删除 |
| 自建技能 | 本机 SQLite | 用户删除即删 |
| 软件目录 / 网站目录 | 目录文件（随版本更新） | 不改代码即可扩展 |
| 授权标记 | 本机单独目录 | 过期失效；**不写入日志** |
| 部署任务 | 本地库 + 日志文件 | 任务结束保留日志 |
| 已安装标记 | 运行目录下清单文件 | 卸载时删除 |
| 账号 | 云端 | 按管理策略 |

### 3.1 数据规则

| 规则 | 要求 |
|---|---|
| 导出 | 本地数据可整体导出为可读格式，不设私有加密锁定 |
| 日志保留 | 最近 30 天，超期自动清理 |
| 卸载/重装 | **不得删除用户资产目录**，须显式询问 |
| 授权标记 | 单独存放，不写入日志 |

## 4. 非功能需求（11 项）

| # | 类别 | 要求 |
|---|---|---|
| 1 | 性能 | 首页可交互 ≤ 1.5s；硬件检测首次 ≤ 5s、刷新 ≤ 8s；方案生成 ≤ 3s（目录 100 项内） |
| 2 | 性能 | 单次部署支持 ≥ 20 个步骤，进度不丢 |
| 3 | 安全 | 只监听回环，不对外网开放；端口不接受外部指定 |
| 4 | 安全 | 下载仅 HTTPS；校验值不匹配删包；解压防穿越与压缩炸弹；**不申请管理员权限、不写注册表、不改环境变量** |
| 5 | 隐私 | 用户数据默认不上传；私域内容默认只走本地模型；联网行为界面可感知 |
| 6 | 可靠性 | 中断后重启可识别未完成任务并提示续装；单软件失败不影响其他 |
| 7 | 兼容 | Win10 1809+ / Win11 x64；WebView2 缺失给安装指引；高 DPI 不重叠 |
| 8 | 易用 | 破坏性操作二次确认；长任务可取消；错误文案含「发生了什么 + 怎么办」 |
| 9 | 无障碍 | 全键盘可操作；滑块与卡片有语义角色；对比度 ≥ 4.5:1 |
| 10 | 可维护 | 模型/软件/网站三类目录以配置文件下发；文案集中管理 |
| 11 | 可观测 | 每次部署产生完整记录：任务号、起止、每步状态与耗时、失败原因 |

### 7.1 Q-03：目录维护与同步频率

| 阶段 | 做法 | 频率 |
|---|---|---|
| **现在（无服务端）** | 助手维护 `catalog.json` / `sites.json`，随客户端发版 | 每次发版 |
| **M4 之后（有服务端）** | 目录移到服务端下发，客户端本地缓存 | 客户端启动检查一次，**每日最多一次** |
| 强制刷新 | 用户可在界面点「刷新目录」 | 不限 |

约定：

- 目录条目**新增/修改不改代码**，只改配置文件；
- 每次变更记录来源与日期（谁加的、依据什么），便于回溯；
- 删除条目前先检查是否有已安装实例，避免误删仍在用的条目。

### 7.2 Q-04：按动作分级，不搞一刀切

**决策：默认直达页面；确有必要的动作（如发布视频）允许受控自动化。**

| 级别 | 程序做到哪一步 | 典型动作 | 约束 |
|---|---|---|---|
| **A0 仅直达** | 打开正确页面，其余用户操作 | 登录授权、支付下单、删除他人数据、改权限 | 无自动化 |
| **A1 辅助自动化** | 程序完成界面操作，**最后一步由用户点** | **发布视频/商品**、批量读取列表数据 | 必须可见窗口 + 人工确认最后动作 |
| **A2 全自动** | 程序完成全部操作，用户事后可撤 | 无副作用的读取（翻页采集） | 仅限读取；限速、单账号串行 |

#### 为什么不是全自动

| 代价 | 说明 |
|---|---|
| 合规 | 平台规则普遍禁止自动化操作，**封的是客户的号** |
| 体积 | Playwright 内核 150–300 MB，**不能内置**，只能按需下载 |
| 维护 | 每个平台的选择器要长期跟着改版维护 |
| 稳定性 | 平台改版即失效，必须有降级路径 |

#### 三条硬约束（A1/A2 都适用）

1. **必须用户在场**：有头窗口可见，不允许无头批量；
2. **对外动作必须人工确认**：发布、提交、扣款这类动作，机器只准备，最后一下人点（与红线 1 一致）；
3. **失败必须能降级**：选择器失效、遇验证码、被风控拦截，立即停并转人工，**不尝试绕过**。

#### 落地方式

- 目录条目增加 `automation` 字段：`page-only`（默认）/ `assisted` / `auto-read`；
- 自动化执行器作为**独立按需组件**下载，不随安装包内置（见 `docs/07` 三层分发）；
- 动作分级的最终判定写在 `docs/10` 第 4.1 节，两边口径一致。

## 8. 风险

| # | 风险 | 应对 |
|---|---|---|
| R-01 | 下载源在部分网络不可达 | 多源 + 国内镜像，失败给官网指引 |
| R-02 | 未配置校验值的软件无法验证完整性 | 上线前补齐；缺失时显著提示 |
| R-03 | 平台登录态依赖浏览器，易失效 | 记录有效期，失效引导重授权 |
| R-04 | 本地模型显存要求高，低配体验差 | 方案阶段直接给「不建议本机运行」 |
| R-05 | 端口注入失败或防火墙拦截 | 启动自检 + 明确报错，允许手动指定 |
| R-06 | 本地存储容量上限 | 超限降级到文件存储，写入失败必须提示 |
| R-07 | 演示数据被误当真实数据 | 正式包不含演示入口（Q-05）；开发包保留标识 |
