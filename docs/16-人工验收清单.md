# 人工验收清单

> 用途：逐项点一遍桌面端，确认功能符合预期。
> 每项写了「操作」和「应该看到」，对不上就记到最后的表格里。
>
> 版本：v0.5.0 ｜ 整理日期：2026-11-18

---

## 0. 前置准备

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 0.1 | 双击桌面「开心同学AI助手」 | 窗口打开，底部状态栏有文字 |
| 0.2 | 保持默认（不配服务器） | 所有本地功能可用，不需要登录 |
| 0.3 | （可选）启动服务端 `_build\kaixin-server.exe` | 控制台出现「服务端（Go）已启动」，默认端口 5080 |

> 服务端账号：`admin` / `kaixin123`（Owner，种子账号）

## 1. 启动与关闭

| 编号 | 操作 | 应该看到 |
|---|---|---|
| 1.1 | 观察底部状态栏 | 有当前页面提示文字 |
| 1.2 | 点右上角最小化 / 最大化 | 窗口正常响应 |
| 1.3 | 再启动一次应用 | **只开一个窗口**，不会开出第二个（单实例保护） |
| 1.4 | 直接点关闭 | 窗口关闭，无额外确认 |

## 2. 新建任务（首页）

| 编号 | 操作 | 应该看到 |
|---|---|---|
| 2.1 | 输入「你好」→ 点发送 | 底部提示已提交；输入框清空 |
| 2.2 | 什么都不输入点发送 | 提示「请先输入内容」 |
| 2.3 | 点「+」选一个文件 | 出现附件标签，可点 ✕ 移除 |
| 2.4 | 点「仅本地 / 允许云端」开关 | 切换并提示；**开启后选云端模型发送会被拒绝** |
| 2.5 | 点麦克风 → 说一句话 → 再点停止 | 录音时显示秒数与波形柱；停止后显示转写文字并插入输入框 |
| 2.6 | 下方「最近提问」 | 点一条会填入输入框；带「技能」的跳到技能部署页 |

> 2.5 需要本地 Whisper 模型（已下载 141 MB）。若提示模型缺失，说明文件被删了。

## 3. 本地资料

| 编号 | 操作 | 应该看到 |
|---|---|---|
| 3.1 | 进入「本地资料」 | 显示真实文件列表与统计（不是 128 份那种假数字） |
| 3.2 | 点「选择资料文件夹」 | 弹出系统文件夹选择器，选中后列表刷新 |
| 3.3 | 点「打开当前目录」 | 资源管理器打开该目录 |
| 3.4 | 选一份资料 → 点「打开文件」 | 用系统默认程序打开 |
| 3.5 | 点「重新扫描」 | 顶部短暂显示「扫描中…」后刷新 |
| 3.6 | 统计卡 | 资料总数 / 已入知识库 / 本周新增 / 占用空间与环境一致 |

## 4. 知识库

| 编号 | 操作 | 应该看到 |
|---|---|---|
| 4.1 | 选一个 txt 或 md → 点「加入知识库」 | 提示「已加入知识库：xxx（N 个切片）」 |
| 4.2 | 看详情区 | 显示「第 1 版 · N 个切片 · 时间」 |
| 4.3 | 修改该文件内容 → 再点「加入知识库」 | 版本变成第 2 版 |
| 4.4 | 点「版本历史」 | 列出第 2 版、第 1 版 |
| 4.5 | 点「回滚到此版」（选第 1 版） | 提示回滚成功，当前变成第 3 版（来源 rollback） |
| 4.6 | 勾选多份资料 → 批量加入知识库 | 提示「成功 N，跳过 N，失败 N」 |
| 4.7 | 勾选已入库的资料 → 批量移出 | 提示移出数量 |
| 4.8 | 选一个 png → 加入知识库 | 提示不支持索引（不会假装成功） |

## 5. 应用助手

| 编号 | 操作 | 应该看到 |
|---|---|---|
| 5.1 | 新建应用，类型选「抖音短视频」 | 列表出现该应用 |
| 5.2 | 选中主应用 → 点「+ 新建子应用」 | 列表缩进出现「└ 子应用名」 |
| 5.3 | 看主应用的计数 | 笔记/资料数是**含子应用**的合计 |
| 5.4 | 新建一条笔记 | 标题或内容为空时不能保存 |
| 5.5 | 笔记右侧点「提炼到资料」 | 自动跳到资料库页，多出一条「（笔记提炼）」待确认资料 |
| 5.6 | 上传任意文件 | 新资料带「待确认」标签 |
| 5.7 | 点「确认」 | 待确认标签消失 |
| 5.8 | 点「编辑关键词」→ 改成「主板, 故障」 | 保存后显示两个关键词标签 |
| 5.9 | 搜索框输入「主板」 | 只剩带该关键词的资料 |
| 5.10 | 切到「数据窗」标签 | 抖音类显示「总发布/本月/本周/今天」；其他类显示「资料总数/本月新增/待确认/占用」 |
| 5.11 | 删除主应用 | 弹出确认，写明「笔记和资料会一起删除，子应用也会一起删除」 |

## 8. 技能部署

| 编号 | 操作 | 应该看到 |
|---|---|---|
| 8.1 | 进入页面 | 直接显示「本机硬件配置」，**没有双模式选择卡片** |
| 8.2 | 点「重新检测」 | 刷新 CPU / 内存 / 显卡 / 磁盘 |
| 8.3 | 选两个技能 | 右上「已选 2 项」实时变化 |
| 8.4 | 看技能卡片 | 显示名称、说明、网址、能力 Lv.N（不写「需 N 核」） |
| 8.5 | 点某个技能「修改」→ 改内容 → 保存 | 匹配结果每行给出软件与理由，未匹配标【无】 |
| 8.6 | 点「生成技能方案」 | 显示步数、总体积、预计耗时、警告 |
| 8.7 | 选一个本地模型（如 Qwen2.5 7B）→ 生成方案 | **末尾自动追加三个云端模型**并给出说明警告（本机核显/内存不足 16G 时） |
| 8.8 | 点「部署」 | 确认弹窗写明安装路径、不需要管理员权限、不修改环境变量 |
| 8.9 | 勾选「强制重新安装」 | 可勾选（已安装的软件会重装） |
| 8.10 | 确认部署 | 进度条跑起来，步骤状态依次变化 |
| 8.11 | 部署中看系统设置 → 语音播报开启 | **完成后会听到中文播报**「部署完成…」 |
| 8.12 | 部署中点「取消」 | 5 秒内变成已取消 |
| 8.13 | 部署中直接点关闭窗口 | 弹确认「部署任务还在进行」 |

## 13. 已知限制（不是 bug）

| 项 | 说明 |
|---|---|
| 云端模型 | 方案里只是「配置项」，不下载；需要在服务商申请 API Key 后填进设置 |
| 语音转写 | 需要本地 Whisper 模型（141 MB），首次转写约 7–12 秒 |
| 恢复备份 | 会清空会话，恢复后需重新登录；仅 Owner 可恢复 |
| 官网 | 已构建但未部署（无域名与备案） |
| 自动更新 | 未做（UPD-03），当前只能手动下载替换 |
| 资料自动采集、系统自主优化 | 未做（CLD-04 / CLD-07） |
| 邀请成员 / 换绑微信 | 未做，按钮禁用并写明原因 |

## 15. 建议的验收顺序

1. **第 1、2、3 章**：确认应用能开、能输入、能看文件（10 分钟）
2. **第 8 章**：技能部署最关键，先看硬件检测与方案生成（10 分钟）
3. **第 4、5 章**：知识库与应用助手（15 分钟）
4. **第 6、7 章**：目标与学习（10 分钟）
5. **第 9、10、11 章**：历史、设置、更新（10 分钟）

全程约 1 小时。**遇到阻断问题先停，把编号发我。**
